# dreamcars — Preservation & Portfolio Roadmap

The repository contains a large interactive HTML demo, JSON configuration/data and After Effects loader source.

## 10 tasks

1. Establish the project's date, product concept and exact personal contribution.
2. Preserve the current HTML demo before modifying or extracting assets.
3. Document how `demo.json` maps into the interactive experience.
4. Identify external libraries/assets embedded in the large HTML file and record attribution.
5. Create a lightweight hosted portfolio snapshot without rewriting historical behavior.
6. Export a modern video/GIF preview from the loader/motion source for quick recruiter review.
7. Capture key screens and interaction states at portfolio-friendly aspect ratios.
8. Improve README navigation so demo, motion, data and context are immediately discoverable.
9. Explain historical technical constraints and what would be architected differently today.
10. Use the project to demonstrate interaction/motion/product craft, not as evidence of modern automotive production infrastructure.

## Portfolio value

Strong historical visual artifact when packaged as interaction and motion design evidence.
